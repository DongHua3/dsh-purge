# 案例：3D 打印点阵结构本科毕业论文（模拟仿真型）

这是本技能唯一一个**从第 00 步走到第 21 步、交付了 docx 与 pdf 的真实项目**。
不是示范稿，是当时的现场文件：`PIPELINE.md`、`DECISIONS.md` 与 20 个项目脚本原样保留。

## 一、这个案例是什么

| 项 | 内容 |
|---|---|
| 题目 | 面向熔融沉积成形的点阵结构参数化建模与准静态压缩性能数值研究 |

| 方向 | 增材制造 / 材料挤出成形（FDM） |

| 运行位置 | `C:\Users\ASUS\Desktop\毕业论文\`（案例目录只保留总控、决策与脚本） |

## 三、哪些可以复用到别的题目

**可以照搬（结构与方法）**

- 22 步的产出物命名与闸门判据（见 `PIPELINE.md` 进度表与 `PAPER_STATE.json` 的 `gates`）。
- 五章中文骨架：绪论 / 理论基础与模型 / 数值试验设计 / 结果与分析 / 结论展望与附录。
- 分章存 md（`manuscript/part0..part5`）——本项目真实事故：重写第 1 章时把摘要整节覆盖掉了。
- 数值校准流水线：模型 → 数据 → 图 → 回填 → 构建 → 终检，**顺序不能改**。
  `sync_numbers.py`（表格）+ `sync_inline_numbers.py`（行内）都要求唯一匹配，宁可不改也不能误改。
- 引用编号由脚本生成 + 逐条审计（`check_citations.py`），手工维护必然错位。
- 无实验数据的声明话术：在摘要、1.4、4.9、5.2、附录 B.4 共五处声明，而不是"很遗憾没做实验"。

**不能照搬（属于这个题目）**

- Gibson–Ashby 的具体标定系数、β = 150、ε_D = clamp(1−1.4ρ̄, 0.45, 0.88)——
  这些是"这个模型在这批文献下的取值"，换材料体系要重新标定。
- 上述任何一个数字。它们只在 18 条曲线 × 320 点、138 设计点这一套数据下成立。
- 12 图 / 17 表的具体切分：换题目后图表预算要按第 09 步的 OUTLINE 重算。

## 四、这个案例留下的三个"反面教材"

1. **BRIEF 的预算与实际不符**：第 01 步写的是"12 图 + 6 表、参考文献 40–50 条、字数 ≥18,000"，
   交付时是"12 图 + **17 表**、**47+54** 条、**23,181** 字"。表数量涨了近三倍，因为设计点与
   统计量太多，表比图更能承载。**教训：图表预算在第 09 步按 OUTLINE 重新确认一次，别让第 01 步的数字
   一路错到交付。**
2. **一次性修补脚本写了 6 个**（`fix_table41.py`、`fix_table45.py`、`fix_layer_section.py`、
   `fix_rsm_inline.py`、`fix_angle_para.py`、`sync_inline_numbers.py`）。这是"模型改了、正文没跟上"
   的直接代价。**教训：数字一律由脚本从 `data/` 回填，正文里不手写数字，这类脚本一个都不该存在。**
3. **`PIPELINE.md` 与 `PAPER_STATE.json` 的时间戳互相矛盾**（日志里 20 步 14:57 通过，
   15:20 又因全链路校准重跑了一次）。**教训：校准后要重写"总检结果"和"校准记录"两张表，
   否则下一次接手的人会以为 14:57 那份是终版。**

## 五、`code/` 里有什么

20 个脚本，全部是**硬编码单项目版**（路径写死在项目根）。它们不是技能包的主版本，
主版本在 `scripts/`（参数化 + CLI）。这里保留是为了回答"当年这活儿具体怎么干的"。

| 脚本 | 干什么 |
|---|---|
| `sim_model.py` | 半解析模型，生成 138 设计点与 18 条应力–应变曲线 |
| `uncertainty.py` | LHS 抽样做参数不确定度传播与排序稳健性（3000 组） |
| `make_figures.py` | 读 `data/` 出 12 图，PNG 300 dpi + 矢量 PDF；启动清理旧图 |
| `sync_numbers.py` / `sync_inline_numbers.py` | 按 `data/` 回填正文表格 / 行内数字（唯一匹配） |
| `report_stats.py` | 导出正文引用的全部统计量，供人工核对 |
| `add_citations.py` / `merge_topic_refs.py` | 批量插入引用（唯一匹配）；把 TOPIC 附录 A 的 13 条并入文献表 |
| `build_references_ordered.py` | 按正文首次引用顺序生成 GB/T 7714 编号（`CITATION_ORDER` 为唯一真源） |
| `check_citations.py` | 悬空引用 / 孤立条目 / 抽样内容对齐 |
| `math2unicode.py` | LaTeX → Unicode（python-docx 无 OMML） |
| `build_docx.py` | 分章 md → 学位论文格式 docx，含 LaTeX 残留自检 |
| `docx_to_pdf.py` | Word COM（回退 WPS COM）导出 PDF |
| `final_check.py` | 12 项终检 + 报告 + 哈希表 |
| `wordcount.py` | 分章中文字数 + 图号连续性（技能的 `scripts/wordcount.py` 是它的通用化版本） |
| `fix_*.py` | 一次性校准修补（反面教材，见第四节） |
