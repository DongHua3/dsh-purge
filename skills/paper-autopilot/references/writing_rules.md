# 写作细则

## 一、章节骨架（研究论文）

```
Title
Abstract（约 250 词）· Keywords（4–6 个）

1 Introduction
  1.1 背景与工程意义
  1.2 已有工作（按机理/方法分组，不要按时间流水账）
  1.3 尚未解决的问题（缺口）
  1.4 本文的工作与贡献
2 Methods
  2.1 物理模型与假设
  2.2 控制方程
  2.3 材料/部件模型
  2.4 数值实现与求解设置
  2.5 验证（与解析解/文献值对比，先声明容差）
3 Results
  3.1 验证性结果
  3.2 主结果（按机制或参数分组，一组一图）
  3.3 参数敏感性
  3.4 与基线的对比
4 Discussion
  4.1 与文献的一致性/差异及原因
  4.2 适用边界
  4.3 局限
  4.4 工程意义与展望
5 Conclusions（只写结论，不带新证据）
Declarations（数据可得性、利益冲突、作者贡献、致谢）
References
```

## 二、摘要的五句结构

写摘要最容易犯的错是"先写摘要再倒推数据"。正确顺序是**结果先算出来，再写摘要**。

1. **背景**一句：这个工程问题为什么重要
2. **缺口**一句：现有做法差在哪
3. **本文做法**一句：做了什么、用什么方法
4. **关键结果**两句：**带具体数字**（衰减百分比、峰值、误差）
5. **意义**一句：对工程实践意味着什么

只写你在结果里**已经算出来**的数字。摘要里写不出来的数字，说明结果还没做完。

## 三、去 AI 味：五个特征与对应改法

机器写的中文学术文本有五个可测的特征。**不是凭感觉"润色一下"，而是按指标改。**

### 1. 段落长度太均匀

真人写作段落长短交错：有的三行，有的十行。AI 生成时倾向每段都差不多长。

- 指标：段落字数的**变异系数 > 0.45**
- 改法：把某个长段拆成两段；把两个相邻短段合并；给关键结论单独成段

### 2. 句子长度太均匀

同理。真人会写很短的判断句，也会写很长的限定句。

- 指标：句长**变异系数 > 0.40**
- 改法：长句断成短句；偶尔用一句话独立成段（但不要滥用）

### 3. 破折号滥用

中英文 AI 文本都爱用 `—` 做插入语。

- 指标：正文 em dash **为 0**
- 改法：断句。`A——也就是 B——导致了 C` → `A 导致了 C。这里的 A 指 B。`

### 4. 规则三连（rule of three）

`高效、稳定且可扩展` 这种三项并列，连着出现就是机器味。

- 指标：每 100 段**少于 2 处**
- 改法：删掉最弱的一项留两项；或者拆成两句各说一件事
- 注意：**不是禁止三连**，是禁止**成串**出现

### 5. 衔接词成套堆砌

`Moreover / Furthermore / Additionally / In addition` 轮着用，段落开头还总一样。

- 指标：这类词每 100 句**少于 2 次**
- 改法：直接删掉衔接词。句子之间的关系靠内容承接，不靠连接词
- 另外：同一句首（前 3 个词）重复**不超过 2 次**

### 额外两条（本项目踩过的坑）

6. **跨节重复整句**：结果和讨论里出现一模一样的句子。审稿人一眼看出是复制粘贴。
   → 讨论里必须**换说法**，或者干脆引用结果而不复述。
7. **数字换说法重说**：同一个数在一段里用两种表述各说一遍。删掉一个。

```bash
python scripts/prose_scan.py manuscript/
```

## 四、证据纪律

| 类型 | 要求 | 不合格的样子 |
|---|---|---|
| 数字 | 能追到本项目输出文件，或标了文献的页码/表号 | "大约是 30% 左右" |
| 中间量 | 能从上游量复算出来 | "由此可得 2.47"（没说怎么得的） |
| 引用 | 作者/年份/标题/期刊四项核过 | 凭记忆写的 DOI |
| 单位 | 换算后所有受影响数字重算 | 换了单位没改数 |
| 对比 | 先声明"这两个量是不是同一回事"再比 | 拿模态刚度和静刚度直接比 |
| 验证 | 先声明容差再比 | 先比完再挑一个能过的容差 |

**查不到就写"未验证"**，并在交付说明里列出来。这一条没有例外——
引用造假是审稿零容忍项。

## 五、局限怎么写

局限要写成**方法学边界**，不是道歉。

| 不要这样写 | 要这样写 |
|---|---|
| 很遗憾我们没能做实验 | 本文是计算研究，结果未经实验验证；实验验证留待后续工作 |
| 我们的模型可能不够精确 | 磁路采用磁阻网络而非场解，因此不解析局部饱和 |
| 数据量有限 | 结论基于 30 组公差抽样，抽样为区间均匀分布而非实测分布 |

判定标准：**删掉"遗憾/可能/有限"这类词之后，这句话还成立吗？** 成立就是边界，不成立就是道歉。

## 六、投稿前必须自己回答的五个问题

1. 摘要里的每个数字，正文里找得到吗？
2. 每条参考文献，作者年份都对吗？
3. 每张图，正文里引用了吗？引用顺序和图号顺序一致吗？
4. 有哪些假设是**读者可能以为是实测**的？都标出来了吗？
5. 如果审稿人说"这个结论不能从你给的数据推出"，你能指出哪张表哪一列支撑它吗？

任何一个答不上来，回到对应的步骤重做，不要带着它投出去。
