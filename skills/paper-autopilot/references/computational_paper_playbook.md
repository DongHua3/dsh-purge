# 纯仿真论文怎么写才专业（第 12、13 步作业指导）

> 面向的现实：**由于现实条件限制，研究只能靠计算机模拟完成，没有条件做实验。**
>
> 这不是缺陷，是**研究方式的边界**。但审稿人默认会拿"没有实验验证"当拒稿理由。
> 本文件给出一整套应对办法——**不是话术，是真能做出来的证据**。

---

## 一、先认清审稿人到底在想什么

仿真论文被拒的真实理由，按出现频率排：

| 审稿人写的 | 他真正想说的 | 能不能补 |
|---|---|---|
| "Lacks experimental validation" | 我不相信你的模型 | **能**，见第三节 |
| "The model is not verified" | 你没证明数值解是对的 | 能，而且成本最低 |
| "Mesh/timestep independence not shown" | 结果可能是离散误差 | 能，半天的事 |
| "Parameters are not justified" | 参数是凑出来的吧 | 能，参数表带来源列 |
| "The conclusions are over-claimed" | 你说得比证据多 | 能，把话说小 |
| "Incremental contribution" | 只是换了个工况 | **不能靠写作解决**，是选题问题 |
| "No uncertainty quantification" | 你的数到底有多准 | 能 |

**除了倒数第二条，其余全部可以在没有实验的情况下解决。**

关键认知：**"没有实验"和"没有验证"是两件事。**
审稿人写的是前者，判的是后者。你要做的是把后者补满，让前者变得不重要。

---

## 二、没有实验时，你手上有什么证据（按强度排序）

```
弱 ────────────────────────────────────────────────► 强

网格无关性   代码验证   解析解对照   跨模型互校   文献实验数据对照   自己的实验
```

**"文献实验数据对照"这一档是被严重低估的。**

你不需要自己搭台架。**别人发表过的实验数据，你拿来对照，就是 validation。**
这是计算力学、CFD、材料建模里的标准做法——顶级期刊上大量纯计算论文都是这么做的。

只要做到：

1. 实验数据的**来源、条件、不确定度**写清楚
2. 你的模型在**同样的条件下**复现同一批数据
3. 按 ASME V&V 20 的框架做**不确定度合成**比较
4. 说清楚**确认域**（模型在哪个参数范围被确认过）

## 三、验证阶梯：五级证据，逐级做

### 第 1 级 · 代码验证（Code Verification）

**问题**：我的求解器实现对不对？

- 与**解析解**比：闭式解、已知本征值、极限情况
- 与**制造解**（MMS）比：反推源项，测观测收敛阶
- **观测阶必须接近理论阶**

`simulate.py check` 自动做这一级。本项目自带模型实测：

```
自由度 周期（RK4 vs 2π√(m/k)）        相对误差 4.4e-16
受迫稳态幅值（时域 vs 解析）            相对误差 9.0e-09
2-DOF 固有频率（特征值 vs 解析根）      相对误差 2.2e-16
观测收敛阶（RK4 理论 4）                实测 3.949
```

**这一级成本最低、说服力最高。没有它，后面全白搭。**

### 第 2 级 · 解验证（Solution Verification）

**问题**：这一次计算本身的离散误差有多大？

- 网格/时间步无关性，至少三套
- 报**观测阶 p**、**Richardson 外推值**、**GCI**
- 安全因子：三套以上取 1.25

**两个坑（本项目的实测教训）**：

1. 网格要**粗到误差还在渐近区**。太细时误差已到机器精度，
   测出来的"阶"是噪声（我们第一版测出 8.39，理论是 4）。
2. 测的量必须是**积分量**，不能是采样峰值。
   采样峰值的误差取决于采样点是否落在波峰上，那是**一阶**收敛，
   与积分器的四阶无关。改用最小二乘拟合幅值后得到 3.949。

### 第 3 级 · 跨模型互校（Cross-model comparison）

**问题**：我的**建模假设**（降阶、简化）影响结论吗？

做法：用**更高保真度**的模型再算一遍同一件事。

例如本项目：2 自由度集总模型 vs 把轴离散成 50 段的有限差分模型。
两者在低频段应该吻合；如果差很多，说明降阶假设不成立。

**这是"模型形式不确定度"（model-form uncertainty）的直接证据。**
审稿人问"你的简化模型可靠吗"，你拿这张对比图回答。

**注意**：这是**互校**，不是**确认**。写作时必须说清楚，
不能把两张图一致说成"模型得到实验验证"。

### 第 4 级 · 文献实验数据对照（Validation against literature）

**问题**：我的模型与真实世界一致吗？

```
1. 找有实验数据的同类研究（同材料、同工况、同尺度）
2. 从论文的图/表里取数据点（有原始数据最好；没有就数字化，并说明方法）
3. 记下实验条件、样本量、报告的误差范围
4. 在相同条件下跑你的模型
5. 按 ASME V&V 20 比较：
       U_val = sqrt(U_num² + U_exp²)
       |E| ≤ U_val  →  在该不确定度水平上无法拒绝该模型
       |E| > U_val  →  不一致，必须解释原因
6. 给出确认域：模型在哪个参数范围内被确认
```

**⚠️ 数字化别人的图要说明**："Data were digitized from Fig. 5 of [ref] using
WebPlotDigitizer; the digitization uncertainty is estimated at ±2 %."

**⚠️ 引用别人实验数据的规矩**：数据本身是别人的成果，要引用，必要时申请授权。
自己数字化后重绘的图，版权风险小，但仍要注明数据来源。

### 第 5 级 · 自己的实验

有当然最好。没有就如实说，**不要用第 3、4 级冒充第 5 级**。

## 四、不确定度量化：没有实验时你的"误差棒"

纯仿真论文没有实验误差，但**不等于没有不确定度**。三类必须分开说：

| 类型 | 来源 | 怎么处理 |
|---|---|---|
| **输入不确定度** | 材料参数、几何公差、边界条件 | 有界均匀抽样（**公差是界限不是 σ**）+ 灵敏度分析 |
| **数值不确定度** | 离散误差、迭代容差 | GCI / Richardson 外推（第 2 级） |
| **模型形式不确定度** | 简化假设、降阶 | 跨模型互校（第 3 级） |

### 报告什么才算够

- 抽样次数 n 与**随机种子**（否则别人无法复算）
- 均值 ± 标准差、**5–95 百分位**、最小值
- **落在阈值之外的样本比例**，并用 Wilson 区间给它的置信区间
- **灵敏度**：哪个输入主导了散布（Spearman 秩相关 / Sobol 指数）

**只给一个"最坏情况"不够，只给均值也不够。分布的形状本身是结论。**

### 灵敏度分析怎么做

| 方法 | 成本 | 给什么 |
|---|---|---|
| 局部（一次一变） | 极低 | 各参数单独影响，**忽略交互** |
| Spearman 秩相关 | 低 | 单调影响排序，配合 MC 一起做 |
| Morris 筛选 | 中 | 快速找出重要参数 |
| **Sobol 指数** | 高 | 主效应 + **交互效应**，论文里最有说服力 |

纯仿真论文建议至少做到 Spearman + Morris；有条件上 Sobol。

## 五、没有实验时，摘要和范围声明怎么写

**不要道歉，要给边界。** 判定标准：删掉"遗憾/可惜/未能"这类词之后，句子还成立吗？

❌ **道歉式**（会强化审稿人的怀疑）：

> Due to practical limitations, we regret that no experiments could be
> performed, which is a major weakness of this study.

✅ **边界式**（把限制变成方法学定义）：

> This is a computational study. The model is verified against closed-form
> solutions to within 1e-8 and its discretisation error is bounded by a grid
> convergence index of 0.8 %. Predictions are validated against the
> experimental data of [ref] over 0–1.0 T, which defines the domain of
> validity. Outside this range the results are extrapolations.

**摘要里写什么**：

> 一句讲问题 → 一句讲方法 → **一句讲验证到什么程度** → 关键结果（带数字）
> → 一句讲确认域边界

把"验证到什么程度"写进摘要，是纯仿真论文取信于人的最快方式。

**局限一节要具体到什么程度**：

| 不要写 | 要写 |
|---|---|
| 模型可能不够精确 | 磁路采用磁阻网络而非场解；对局部饱和的偏差估计 ≤8 %（见第 4.3 节） |
| 缺乏实验验证 | 未经本文实验确认；已对照 [ref] 的 0–1.0 T 实验数据，超出该范围属外推 |
| 参数存在不确定性 | 材料参数按 ±10 % 有界均匀抽样（n=400，种子 0），性能裕度 30.1±0.6 %，5–95 百分位 10.7–50.2 % |

**左边是态度，右边是数据。审稿人只认右边。**

## 六、审稿人常见质疑与预备答案

写论文时就把这些答案准备好，放进正文或补充材料：

| 质疑 | 你要有的 |
|---|---|
| "没有实验验证" | 第 1–4 级证据表 + 确认域声明 |
| "模型太简化" | 第 3 级跨模型互校 + 模型形式不确定度量化 |
| "参数从哪来" | 参数表**带来源列**（自测/文献+编号/假设） |
| "网格无关吗" | GCI 表 + 观测阶 |
| "结论超出数据支持" | 确认域 + 外推标注 |
| "结果无法复现" | 数据集 DOI + 代码 DOI + 随机种子 + 运行顺序说明 |
| "只挑好工况展示" | 全工况扫描图 + **最坏情况**说明 |
| "数值误差有多大" | 第 2 级 + 不确定度合成 |
| "为什么不用更高保真模型" | 说明成本-精度权衡，并用第 3 级量化降阶误差 |

**"最坏情况"那一条特别加分。** 本项目的一个例子：最坏 MRE 应变出现在
**去磁状态**（5.74 %），不是在受控状态，而且超出许用限值。
把这个写进摘要，比只报"控制效果好"可信得多——**它证明你真的算全了**。

## 七、专业性清单（投稿前逐条打勾）

**模型与参数**
- [ ] 控制方程写全，符号表清晰
- [ ] 全部假设**显式列出**（不是散落在正文里）
- [ ] 参数表带单位、来源、取值理由
- [ ] 没有任何"从结果反推"的参数

**验证**
- [ ] 代码验证：与解析解/制造解对照，报观测收敛阶
- [ ] 解验证：三套以上网格/时间步，报 p、Richardson、GCI
- [ ] 跨模型互校（至少一个更高保真度模型）
- [ ] 文献实验数据对照（有同条件数据就必须做）
- [ ] 明确写清做过的是 verification 还是 validation

**不确定度**
- [ ] 输入不确定度：有界抽样 + 种子 + n
- [ ] 数值不确定度：GCI
- [ ] 模型形式不确定度：跨模型差异
- [ ] 灵敏度分析（至少 Spearman）
- [ ] 报分位数与越界比例，不只是均值

**写作**
- [ ] 摘要里写了验证程度与确认域
- [ ] 局限一节是**数据**不是**态度**
- [ ] 结论没有超出确认域
- [ ] 最坏情况写出来了
- [ ] **过了去 AI 痕迹判定项**（第 19 步）

**可复现**
- [ ] 数据有溯源（`.prov.json`）
- [ ] 代码与数据存 Zenodo 拿 DOI
- [ ] 参考文献全部核验过（无查不到、无撤稿）

## 八、给 agent 的执行纪律

1. **不许把 verification 说成 validation。** 这是审稿人最反感的 over-claim。
2. **没有实验就在摘要里写明**，并且**同时写出验证到了什么程度**——
   只写"没有实验"是自曝其短，写"验证到什么程度"才是专业。
3. **先做第 1、2 级证据**（成本最低、说服力最高），再做第 3、4 级。
4. **不确定度必须做**，它是纯仿真论文唯一的"误差棒"。
5. **重复运行必须逐位一致**，随机部分必须给种子。
6. **去 AI 痕迹不能省。** 方法和结果部分要写出**只可能来自实际计算**的细节
   （网格规模、求解器设置、收敛容差、异常值怎么处理的）——
   这些细节既是专业性的体现，也天然去 AI 味。

## 九、配套工具（都是实测可用的）

| 命令 | 做什么 |
|---|---|
| `simulate.py check --model X` | **第 1 级**：代码验证。自带模型 9/9 通过 |
| `simulate.py run --study speed_sweep` | 扫频响应（带溯源） |
| `simulate.py run --study material_law` | 材料本构 G′(B)、tan δ(B) |
| `simulate.py run --study current_response` | 调谐曲线 |
| **`simulate.py run --study validate`** | **第 3 级**：降阶模型 vs 高保真模型，量化**模型形式不确定度** |
| **`simulate.py run --study uncertainty`** | **不确定度预算**：有界抽样 + Spearman 灵敏度排序 |
| `simulate.py run --study monte_carlo` | 公差传播（有界均匀抽样 + 种子） |
| `simulate.py provenance --data data/` | 数据溯源核查 |

### 自带模型的实测结果（可以直接引用为方法学示例）

**代码验证 9/9 通过**：

```
A. 自由振动周期（RK4 vs 2π√(m/k)）              4.4e-16
B. 受迫稳态幅值（时域 vs 解析）                  9.0e-09
C. 2-DOF 固有频率（特征值 vs 解析根）            2.2e-16
D. 2-DOF 峰值（时域 vs 频域）                   1.3e-08
E. 观测收敛阶（RK4 理论 4）                      3.949
G. 高保真基函数 vs 解析梁解（564.058 vs 563.793 Hz）  4.7e-04
H. 降阶 vs 高保真 首阶盘模态差                  1.1e-02
F. 重复运行逐位一致                              是
```

**第 3 级 跨模型互校的实测结果**（2-DOF 降阶 vs 高保真梁模型）：

| 电流 | 平均偏差 | 最大偏差 |
|---|---|---|
| 0.0 A（去磁） | 4.26 % | 22.6 % |
| 0.333 A（最佳恒流） | 4.90 % | 28.8 % |
| 1.0 A（饱和） | 8.28 % | **89.6 %** |

**这就是要写进论文的数字。** 它说明：降阶模型在远离共振时够用，
但在共振点附近误差可达几十个百分点——**这是必须报告的模型形式不确定度，
不是可以藏起来的缺陷。**

**第 4 级 不确定度预算的实测输出**（n=150，种子 0）：

```
裕度均值        5.054 %     裕度标准差   1.457 %
5 百分位        2.737 %     95 百分位    7.357 %
最小裕度        2.402 %
灵敏度排序（Spearman）：G_inf 0.296 · pad_t -0.251 · m1 -0.233
                        · tan_delta_inf 0.204 · shaft_d -0.128
```

**"哪个参数主导散布"是纯仿真论文必须回答的问题**——它决定了你做实验时该控什么，
也决定了你的结论有多稳健。

### 第 4 级（文献实验数据对照）怎么接进来

`simulate.py validate` 目前做的是**跨模型互校**。要接文献实验数据：

1. 把文献实验数据数字化成 CSV：`x, y_exp, y_err`
2. 在模型里加一个 study，读该 CSV，在**相同条件**下算模型值
3. 按 V&V 20 算 `U_val = sqrt(U_num² + U_exp²)`，比较 `|E|` 与 `U_val`
4. 输出确认域

详见 `references/simulation_vv.md` 第四节。
